# Security Policy

## Supported versions

This repository is an academic defensive-security project. Security fixes are applied to the latest commit on the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, credentials, personal data, or sensitive scan results in a public issue.

Use GitHub's private vulnerability reporting feature when it is available. Otherwise, contact the repository owner privately through the contact information on their GitHub profile.

Include only the information needed to reproduce the problem safely:

- affected component and version or commit;
- impact and expected behavior;
- minimal reproduction steps;
- suggested mitigation, if known.

Do not include real credentials, unauthorized scan results, or data belonging to third parties.

## Scope and responsible use

The project processes Nmap output and can integrate with infrastructure inventory systems. Run it only against systems you own or are explicitly authorized to assess. Reports should distinguish exposed services from confirmed vulnerabilities and must not be used as proof of exploitability without further validation.
